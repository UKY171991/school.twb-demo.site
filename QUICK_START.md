# 🚀 Quick Start - Populate Dummy Data

## One Command Setup

Run this single command to get your school management system ready with comprehensive test data:

```bash
php artisan school:populate-dummy-data --fresh
```

## What This Creates

✅ **3 Complete Schools** with all data  
✅ **675 Students** across all grades  
✅ **24 Teachers** with qualifications  
✅ **2,025 Marksheets** with realistic grades  
✅ **13,500 Attendance Records** (30 days)  
✅ **Login Accounts** ready to use
